# 👤 Personal Profile App

A clean, responsive and interactive **Personal Profile App** built using HTML, CSS and JavaScript. The application displays a student's profile including their photo, name, college/branch, bio, skills and social/contact links.

## ✨ Features

### 📋 Basic Features

- Profile photo
- Student name
- College / branch
- Short bio
- Skills section
- Social/contact buttons
- Clean and responsive user interface

### 🚀 Advanced Features

- ✏️ Edit profile information
- 📷 Upload and change profile photo
- 🏷️ Add new skills
- ❌ Remove skills
- 💾 Automatically save profile using Local Storage
- 🌙 Dark mode
- ☀️ Light mode
- 📤 Share profile
- 📋 Copy profile details
- 🔗 GitHub link
- 💼 LinkedIn link
- 📸 Instagram link
- ✉️ Email button
- 📊 Profile completion percentage
- 📱 Mobile-first responsive design
- 🔄 Reset profile option
- Smooth animations and interactive buttons
- No backend or database required

## 📱 Profile Information

The profile contains:

- Profile photo
- Name
- College / branch
- Short biography
- Technical and creative skills
- GitHub
- LinkedIn
- Instagram
- Email

## 🏷️ Skills

Users can:

- Add skills
- Remove skills
- Add skills using the Enter key
- Have up to 12 skills
- Prevent duplicate skills

## 📊 Profile Completion

The application automatically calculates profile completion based on information such as:

- Name
- College / branch
- Bio
- Skills
- Profile photo
- GitHub
- LinkedIn
- Email

A progress bar displays the completion percentage.

## 🌙 Theme

The application supports:

- Light mode
- Dark mode

The selected theme is saved in the browser and remains active after refreshing the page.

## 💾 Data Storage

Profile information is saved using the browser's **Local Storage**.

This allows the profile to remain available after refreshing the page without requiring a database or server.

The profile photo is also stored locally in the browser.

## 📤 Sharing

The **Share Profile** button uses the browser's built-in sharing functionality when available.

On browsers that do not support native sharing, the application attempts to copy the website link instead.

## 📋 Copy Profile

The **Copy Details** button copies the complete profile information to the clipboard.

The copied information includes:

- Name
- College / branch
- Bio
- Skills
- GitHub
- LinkedIn
- Instagram
- Email

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- FileReader API
- Clipboard API
- Web Share API
